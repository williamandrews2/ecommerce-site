# E-commerce Site

## About this project

This project follows [Web Dev Simplified's Next.js E-Commerce tutorial](https://www.youtube.com/watch?v=iqrgggs0Qk0)
to learn/reinforce patterns I have learned/am learning: Next.js App Router, Prisma ORM, Stripe payment integration, transactional email, and Zod validation.
Reference implementation can be found [here](https://github.com/WebDevSimplified/next-js-ecommerce-mvp).

**Stack:** Next.js, TypeScript, Tailwind, Prisma, Postgres, Stripe, Resend, Zod

## Getting Started

First, run the development server:

```
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
